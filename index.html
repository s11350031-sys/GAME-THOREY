Foundation 01

P-position 與 N-position

不是看先手或後手的身分，而是看「現在輪到行動的人」是否有必勝策略。

P-positionPrevious-player winning：輪到的人沒有必勝策略，雙方最佳應對時會輸。
N-positionNext-player winning：輪到的人至少存在一個必勝走法。
N ⇔ 存在一步可以走到 P
P ⇔ 所有合法下一步都是 N
終止局面在「正常玩法：無步可走的人輸」下是 P-position。
一個局面只要有「一條」通往 P 的路就是 N；P 必須「所有」路都通往 N。

標記玩家，避免弄混

(12,19,27)先手輪到 → (8,19,27)後手輪到

如果後面的局面是 P，意思是後手接到必敗局面，不是後手擁有必勝策略。

互動練習：拿 1 或 2 顆

點選目前顆數，觀察輪到的人是 P 還是 N。

Foundation 02

mex 與 XOR 不要混淆

單一局面求 SG 用 mex；多個獨立局面合併 SG 用 XOR。

SG 值的遞迴定義

g(n) = mex { g(m) : n → m 是合法一步 }
列出合法走法：例如 S={1,3,4}，n=5 可到 4、2、1。
查下一步的 SG：g(4)=2、g(2)=0、g(1)=1。
求 mex：mex{2,0,1}=3，因此 g(5)=3。
mex 的集合放的是下一個局面的 SG 值，不是剩下的石子數。

mex 快速對照

集合mex原因
∅00 沒出現
{0}1缺 1
{1}0缺 0
{0,1,3}2缺 2

XOR（互斥或）

每一個二進位欄位分開計算；同一欄有奇數個 1 → 1，偶數個 1 → 0。

1 ⊕ 3 ⊕ 2 = 01₂ ⊕ 11₂ ⊕ 10₂ = 00₂ = 0
獨立子遊戲：SG(局面 A + 局面 B) = SG(A) ⊕ SG(B)。
整體 XOR = 0 ⇒ P-position；非 0 ⇒ N-position。

互動：試算 mex

Question 01

S = {1,3,5,7}：找全部 P-position

每回合可以拿走 1、3、5、7 顆，不能超過目前石子數。

觀察奇偶性就能證明

n=0 是 P：無法移動。
偶數 n：減去任何奇數，剩下奇數。若奇數都是 N，偶數就是 P。
奇數 n：一定能減 1 變成偶數 P，因此奇數是 N。
P = {0,2,4,6,8,10,…}
N = {1,3,5,7,9,11,…}
Q1 答案：所有非負偶數都是 P-position。
證明 P 不是只舉出一種會輸的走法；要說明從偶數出發，所有合法走法都變成奇數 N。

互動：查看前 20 個局面

Question 02

Chomp 巧克力：唯一必勝第一步

從上到下每排長度 1、5、8；左下角是毒巧克力。

規則與答案

選取一格後，會吃掉該格以及它上方、右方所構成的矩形區域；吃到左下角毒巧克力者輸。

唯一必勝第一步：選最下排從左數第 3 格，留下每排長度 (2,2,1)（以下以「下、中、上」順序記錄）。

這個 (2,2,1) 是 P-position：對手不管怎麼吃，都能找到反制走法。請注意：(1,1,1) 不是 P-position，因為輪到的人可吃掉上方普通格，留下毒格給對手。

互動棋盤：點選巧克力

顯示方式：上排 1 格、中排 5 格、下排 8 格。按下後觀察局面；「示範必勝步」會標示正確選格。

選擇任一格開始。

考試書寫框架

先手從下排左數第 3 格開始。
局面變成 (2,2,1)，由後手接手。
驗證此局面所有合法下一步都能被回應到 P-position，故它是 P-position。
因此原局面為 N-position，先手有必勝策略。

此題的矩形方向、行長順序均以原始圖形為準；本頁採「下、中、上」記法。

Question 03

Nim (12,19,27)：找所有必勝步

每次只能從其中一堆拿走任意正整數顆，最後拿完者獲勝。

第一步：轉成二進位

12 = 01100₂
19 = 10011₂
27 = 11011₂
────────────
XOR = 00100₂ = 4
初始 XOR = 4 ≠ 0，因此原局面是 N-position。要找拿完後 XOR = 0的走法。

第二步：找哪堆要改

12 ⊕ 4 = 8
12 → 8（從第一堆拿走 4 顆）
8 ⊕ 19 ⊕ 27 = 0

其他堆若做 19 ⊕ 4 = 23、27 ⊕ 4 = 31，都會變大，不能用「拿石子」完成。

Q3 所有必勝第一步：唯一一種，第一堆 12 → 8，也就是拿走 4 顆。

Question 04

Subtraction：S = {1,3,4}

求 0 ≤ n ≤ 15 的 SG 函數；每次只能拿走 1、3、4 顆。

從 n=0 往上推

g(n)=mex{g(n−1), g(n−3), g(n−4)}
只放入 n−s ≥ 0 的合法項
g(0)=mex(∅)=0。
g(1)=mex{g(0)}=mex{0}=1。
g(2)=mex{g(1)}=mex{1}=0；不能拿走 3 或 4 顆。
g(3)=mex{g(2),g(0)}=mex{0,0}=1。
g(4)=mex{g(3),g(1),g(0)}=mex{1,1,0}=2。
特別注意：Q4 的 g(2)=0，不是 1 或 2。因為 n=2 時只能拿 1 顆。

Question 05

拿偶數顆，或移除單顆整堆

允許從任一堆拿走任意正偶數顆，或移除一整堆恰好只有 1 顆的石子。

關鍵：n=2 只能拿 2 顆

g(0)=0，終止局面。
g(1)=mex{g(0)}=1，因為可以移除一整堆 1 顆。
g(2)=mex{g(0)}=1，只能拿走 2 顆；不能拿走 1 顆。
g(3)=mex{g(1)}=mex{1}=0，因為只能拿 2 顆。
g(4)=mex{g(2),g(0)}=mex{1,0}=2。
Q5：g(2)=1。注意與 Q4 的 g(2)=0 不同，因為合法走法不同。

完整 SG 表

g(2k−1)=g(2k)=k　(k≥1)

上式是此題單堆 SG 的規律；n=0 另有 g(0)=0。多堆時，將各堆 SG 值做 XOR。

互動：自己選 n

Question 06

Kayles：13 根保齡球瓶

第 2 根已倒下，剩下 1 根與連續 11 根兩段。可打倒一根或相鄰兩根。

(i) 證明是 N-position

SG = g(1) ⊕ g(11) = 1 ⊕ 6 = 7 ≠ 0

因此輪到行動的人有必勝策略，原局面為 N-position。

(ii) 如何找必勝步？

若從連續 11 根中打倒一根，左右剩下 a、b 根：

a + 1 + b = 11　⇒　a+b=10

保留原本孤立的 1 根，目標是：

g(1) ⊕ g(a) ⊕ g(b) = 0

查表：g(3)=3、g(7)=2，恰好：

1 ⊕ 3 ⊕ 2 = 0
所以可以打倒第 6 根（留下 3、7 根），或第 10 根（留下 7、3 根）。

如果打倒兩根呢？

這時 a+b=9，逐一檢查 0+9、1+8、2+7、3+6、4+5 的 XOR，沒有任何組合能得到 0。所以本題的必勝第一步是打倒一根。

互動：點選要打倒的保齡球瓶

第 2 根已倒下。點選一根（或先選「打兩根」再點起點）看新的 SG 值。

選擇一根保齡球瓶來測試。
表格的 y 是左側的 0、12、24…，z 是上方的 0～11；格子值為 g(y+z)。這只是查單一連續段長度的索引，不是兩個獨立遊戲的 XOR。

考試必勝策略四步驟

看到陌生題目，先套流程，不要急著猜哪一步會贏。

確認規則：每回合能拿什麼？終止條件是什麼？是否為正常玩法？
求局面類型：單堆用 mex 算 SG；多個獨立子遊戲用 XOR。
找合法一步：把走完後的 SG（或整體 XOR）變成 0。
標清楚誰接手：先手行動 → 後手面對 P；後手任意行動 → 先手再恢復 P。
Nim 專用捷徑：若 X = a₁ ⊕ a₂ ⊕ … ≠ 0，嘗試把某一堆 aᵢ 改成 aᵢ ⊕ X；只有新數量更小才是合法必勝步。
常見失分：把 mex 當作拿走後剩下的顆數、把 XOR 當加法、把 P-position 當作「現在輪到的人會贏」、沒驗證移動是否合法。
